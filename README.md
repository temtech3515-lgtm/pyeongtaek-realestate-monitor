# 평택 가재지구 경쟁매물 모니터 v2

단지 ID를 수동 입력해야 하는 구조를 줄이고, 정확한 단지명/별칭을 이용해
단지 ID를 발견한 뒤 매물을 조회하도록 수정한 버전이다.

추적:
- 지제역반도체밸리해링턴플레이스: 전체동 고층, 301~305동 및 304동 별도
- 지제역반도체밸리쌍용더플래티넘: 전체동 고층
- 지제역반도체밸리제일풍경채(2BL): 전체동 고층
- 지제역더샵센트럴시티: 84㎡ 안팎 고층
- e편한세상지제역: 84㎡ 안팎 고층

주의:
1. 네이버의 비공식 내부 endpoint를 사용하므로 네이버 변경에 따라 수정이 필요할 수 있다.
2. 로그인/쿠키/캡차 우회는 하지 않는다.
3. '삭제'는 관찰된 공개 매물 결과에서 사라졌다는 뜻이며 실제 계약/매각을 의미하지 않는다.
4. 첫 실행 후 data/raw.json에서 실제 응답 구조를 확인해 normalize 필드를 보정할 수 있다.
